# Performance and tests (Opportunistic Labs fork)

## Running

    ninja test                # build and run every framework's unit tests
    ninja <framework>/test    # one framework, e.g. ninja scope/test
    ninja <framework>/bench   # run its benchmark_* functions with timings
    Frameworks/scope/rust/parity/run.sh   # Rust scope selectors vs original C++

Test executables are generated by `bin/gen_test` from each framework's
`tests` globs (see `Target.tests` in `bin/rave`).

## Grammar parsing baseline (`ninja parse/bench`)

Apple M-series, release config, real grammars from the installed bundles,
inputs concatenated from this repository. Seconds (two runs each).

| Benchmark        | Size | `-Os` | `-O2`  |
|------------------|------|-------|--------|
| C++              | 4 MB | 6.88–6.91 | 6.66–6.79 |
| Objective-C++    | 2 MB | 5.36–5.40 | 5.21–5.25 |
| Python           | 1 MB | 0.85  | 0.81–0.82 |
| Markdown         | 2 MB | 0.31  | 0.30  |
| Ruby             | 1 MB | 0.27–0.28 | 0.26 |

Lines longer than 4096 bytes are only parsed up to that point
(`kParserMaxLineSize` in `Frameworks/parse/src/parse.cc`).

Profile of the C++ benchmark (`sample`): ~60 % in Onigmo regex matching
(`match_at`, `forward_search_range`), ~15 % malloc/free, ~9 % `apply_rules`,
~2 % scope selector matching.

Release builds use `-O2` (was `-Os`): 2–4 % faster parsing on every grammar,
+523 KB (≈9 %) app binary.
